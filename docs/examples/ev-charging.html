Example: EV Charging

This example shows a complete EV charging session using the Web Charging Gateway. It demonstrates the full online charging flow: authorize → charge → unlock, including how to handle multiple service elements and partial failures.

Scenario: A driver connects their EV to a charging station identified by VIN EV-VIN-123456789. The station requests authorization for up to 50 kWh and one concurrent session slot. After charging, it reports the actual consumed energy.

PortaBilling Setup​

Before running this example, the PortaBilling administrator should have configured:

  • Account ID: EV-VIN-123456789
  • Product with two usage charges:
    • Access code ENERGY → tariff with destination KWh
    • Access code SESSION → tariff with destination Session

Step 1: Authenticate​

curl -X POST https://<host>/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=api-user&password=api-pass"

Store the returned access_token for subsequent requests.

Step 2: Authorize Energy and Session Slot​

When the driver connects, authorize both service elements — the energy (kWh) and the concurrent session slot:

curl -X POST https://<host>/services/EV-VIN-123456789/auth \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "service_elements": [
      {
        "session_id": "charging-session-001",
        "service_type": "Quantity",
        "access_code": "ENERGY",
        "item": "KWh",
        "units": 50,
        "lock_period": 7200
      },
      {
        "session_id": "charging-session-001",
        "service_type": "Quantity",
        "access_code": "SESSION",
        "item": "Session",
        "units": 1,
        "lock_period": 7200
      }
    ]
  }'

Successful response:

  "success": true,
  "service_elements": [
    {
      "timestamp": "2024-05-17 12:00:00",
      "billing_session_id": "7B6AA461 4C5C21EF D47D5CBE AD918421",
      "session_id": "charging-session-001",
      "service_type": "Quantity",
      "access_code": "ENERGY",
      "item": "KWh",
      "user_id": "EV-VIN-123456789",
      "currency": "USD",
      "units": 50,
      "locked_units": 50,
      "lock_period": 7200,
      "expires_at": "2024-05-17 14:00:00"
    },
    {
      "timestamp": "2024-05-17 12:00:00",
      "billing_session_id": "8C7BB572 5D6D32FG E58E6DCF BE029532",
      "session_id": "charging-session-001",
      "service_type": "Quantity",
      "access_code": "SESSION",
      "item": "Session",
      "user_id": "EV-VIN-123456789",
      "currency": "USD",

  "unprocessed_service_elements": [],

  "error_detail": "None"
}

Important: Save the billing_session_id values from the response — you will need them for the charge and unlock steps.

Step 3: Charging Completes — Report Actual Consumption​

The driver charged 23 kWh. Report the actual consumption:

curl -X POST https://<host>/services/EV-VIN-123456789/charges \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "perform_authorization": false,
    "service_elements": [
      {
        "billing_session_id": "7B6AA461 4C5C21EF D47D5CBE AD918421",
        "session_id": "charging-session-001",
        "service_type": "Quantity",
        "access_code": "ENERGY",
        "item": "KWh",
        "units": 23
      },
      {
        "billing_session_id": "8C7BB572 5D6D32FG E58E6DCF BE029532",
        "session_id": "charging-session-001",
        "service_type": "Quantity",
        "access_code": "SESSION",
        "item": "Session",
        "units": 1
      }
    ]
  }'

Response:

{
  "success": true,
  "service_elements": [
    {
      "timestamp": "2024-05-17 13:30:00",
      "billing_session_id": "7B6AA461 4C5C21EF D47D5CBE AD918421",
      "session_id": "charging-session-001",
      "service_type": "Quantity",
      "access_code": "ENERGY",
      "item": "KWh",
      "user_id": "EV-VIN-123456789",
      "i_user": "12345",
      "units": 23,

      "charged_amount": 3.45
    },

  "unprocessed_service_elements": [],

  "error_detail": "None"
}

Charging automatically releases the lock in PortaBilling — you do not need to call /unlock after a successful charge.

Step 4 (Optional): Unlock if Cancelling Without Charging​

If the session is cancelled before charging (e.g., driver disconnects without charging), release the locked resources:

curl -X DELETE https://<host>/services/EV-VIN-123456789/unlock \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "billing_session_id": "7B6AA461 4C5C21EF D47D5CBE AD918421",
    "session_id": "charging-session-001",
    "service_type": "Quantity",
    "access_code": "ENERGY",
    "item": "KWh"
  }'

Repeat for the SESSION element.

Handling Authorization Failure​

If the account has insufficient balance or has reached its quota, the authorization will partially or fully fail.

Example: Second element fails (quota exceeded)

{
  "success": false,
  "service_elements": [],
  "failed_service_elements": [
    {
      "timestamp": "2024-05-17 12:00:00",
      "billing_session_id": "7B6AA461 4C5C21EF D47D5CBE AD918421",
      "session_id": "charging-session-001",
      "service_type": "Quantity",
      "access_code": "ENERGY",
      "item": "KWh",
      "error": "Authorization error.",
      "error_detail": "Requested quantity exceeds the allowed quantity of units."
    }
  ],
  "unprocessed_service_elements": [
    {
      "billing_session_id": null,
      "session_id": "charging-session-001",
      "service_type": "Quantity",
      "access_code": "SESSION",
      "item": "Session",
      "units": 1
    }
  ],
  "error": "None",
  "error_detail": "None"
}

What happens:

  • The ENERGY element failed — it appears in failed_service_elements with an error
  • The SESSION element was not attempted — it appears in unprocessed_service_elements
  • The gateway automatically sends an unlock for the ENERGY element (even if it was momentarily locked before the check failed)
  • No charge is applied; the driver should be shown an error message

Your application should: Check success, inspect failed_service_elements for error details, and inform the user accordingly. Do not proceed with the session.
